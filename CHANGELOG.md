# Changelog

All notable DecoTrack changes are documented here.

## [0.1.0] - Initial mobile prototype
- Created the primary Expo / React Native mobile app for Android-first development.
- Added Lithuanian and English language switching.
- Added light and dark appearance switching.
- Added overview dashboard, tools, bags, projects and transfer history.
- Added local device persistence with AsyncStorage.
- Added QR code display and camera scanning.
- Added demo inventory and sample projects.
- Clarified that cloud synchronization, authentication and production-grade audit history are not yet implemented.
